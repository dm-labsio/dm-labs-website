# Visual design direction after checkpoint 04 — richer visual design, scheduled later

The user wants stronger visual interest and a homepage hero with a real wow factor, beyond the current light pass. The current hero remains the functional baseline while checkpoint 05 finishes shared buttons/header/navigation. Do not prematurely declare the homepage visually complete.

Add these bounded checkpoints after the shared controls, before the corresponding page-family finishing passes:

1. **Hero and motion research:** search current primary library documentation and public desktop/mobile examples. Compare Anime.js (user reference), the existing Framer Motion stack, and other suitable hero/SVG/canvas/3D libraries on visual quality, licensing, bundle/runtime cost, touch behavior, reduced motion and maintenance. Research is explicitly queued; no library is selected by this note. Prototype two or three distinct directions using the supplied brand assets, with a purposeful mobile composition and immediate readable copy/CTA. Keep native scrolling; no return to the retired pinned scrub.
2. **Navy background art direction:** prioritize the supplied dark/navy backgrounds (including IMG-001–004, 041–044, 053 and 055 after individual review). Plan their placement as genuine section backgrounds, not just small illustrations on otherwise pale pages. Inspect the existing neon cursor trail against each composition. Preserve its visibility on fine-pointer desktop without making mobile interaction depend on a cursor. Keep text contrast and mobile crops deliberate.
3. **Editorial layout exploration:** develop distinct, engaging layouts for the homepage, process, services and remaining page families. Explore asymmetric compositions, large image areas, alternating density, narrative sequences, oversized type and purposeful motion. Choose treatments that guide reading and reward exploration. Removing icons is only one step; replacing every section with a repetitive list is not the intended final design.
4. **Complete decorative-icon audit:** revisit process first, then service details, FAQ/contact, pricing and shared components. Identify generic pictograms/capsules still present, and replace them with relevant imagery, branded graphics, typographic or editorial structures. Preserve functional navigation/controls and each demo's own identity. Track this per page/language rather than claiming a global removal.
5. **Page-by-page visual engagement QA:** apply chosen directions in small EN/EL/HE batches. Verify content retention, reading hierarchy, image relevance, interaction cues, keyboard/touch/reduced-motion behavior, mobile performance and no regressions after each batch. Interesting movement must not block reading or delay the offer. Preview only throughout.

These additions supplement the existing consultation, services/process, examples, editorial/legal and final-regression packages; they do not replace their copy or functional gates.
