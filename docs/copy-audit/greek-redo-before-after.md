# Greek redo: before and after (3 October 2026)

The owner asked for a second pass on every Greek page from Batches A to D: as native as possible, and using the words Greek web design studios actually use. The method is the same one we used for Hebrew round 2 (see the "Method" section in `voice-guide.md`): take only the facts from the English, write each line from scratch, and read it aloud as if it were a chat reply.

No facts, prices, page counts, revision rounds or promises changed. The tests that pin hero lines, deliverable counts and the Enterprise price line all still pass.

## What changed across the board

| Change | Why |
|---|---|
| "Άψογη προσαρμογή σε κινητά" → **"Responsive σχεδιασμός"** (service name, menus, cards, pricing, FAQ) | This is the term Greek studios use on their own sites. The old name was long and read like a description, not a service. |
| "Ασφάλεια και φροντίδα" → **"Ασφάλεια και συντήρηση"** | "Φροντίδα" is a word-for-word "care". Greek clients ask for "συντήρηση". |
| "κατεύθυνση (του σχεδιασμού)" → **"σχεδιασμός"** (3 places) | "Direction" is an English agency concept. Greek: "σας δείχνουμε τον σχεδιασμό". |
| "&" in labels → **"και"** | Greek running text and labels use "και". |
| Title Case → **sentence case** (demo slogans, buttons, team roles) | Greek doesn't use English title case. |
| Fewer sayings on the homepage | Five sayings in one block reads like a phrasebook. We kept one per section at most. |
| Two slang risks removed | "πηδάει / πηδήματα" (a page that jumps) and "όσο είναι ζεστοί" (about people) both have a rude slang reading. |
